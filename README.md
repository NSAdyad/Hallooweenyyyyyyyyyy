# Halloween Interactive World

GitHub-ready flat build.

## Important
After unzipping, **all project files are in one single folder**. There are no asset subfolders.

For GitHub's web uploader, upload the files from that one folder in batches if needed. Do not rename files and do not create an `assets` folder.

The landing page uses `landing-background.jpg`. The interface is designed around the supplied Halloween landing artwork and the supplied reference screens for quiz results, Fastest Finger First, Restaurant Scenarios, and Complete Restaurant Experience.

This build is a front-end classroom prototype. True multi-device real-time sessions require a realtime backend; the interface includes isolated session-code controls ready for that connection.
